Each person needs a free Strava API app. This takes about 2 minutes and you only do it once.

How to create your free Strava API app ›
  1. Go to strava.com/settings/api
  2. Fill in:
    Name: Running Coach
    Category: Other
    Website: http://localhost
    Callback Domain: {{ callback_domain }}
  3. Click Create
  4. Copy the Client ID and Client Secret shown
